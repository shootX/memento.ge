# shared

Low-risk cross-package artifacts for the monorepo. Runtime code in `web/` and `app/` is unchanged in this pass.

- `MOBILE-API.md` — mobile HTTP contract (canonical copy; also under `docs/`)
- `brand-palette.json` — brand color tokens aligned with `web/tokens.css` and `app/src/theme/colors.ts`
- `api-contract.ts` — read-only TypeScript shapes for documentation and future import
